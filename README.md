# 🌾 AgroSense – Smart Agriculture & Agronomy Assistant

AgroSense is an intelligent agricultural management platform designed to help farmers make data-driven decisions for crop selection, farm management, weather monitoring, and agricultural problem solving. The project combines **machine learning, generative AI, weather APIs, and a responsive web interface** into a single agriculture-focused application.

### 🚀 Key Features

* 🤖 **AI Agricultural Chatbot** – Provides agriculture-related assistance using Google Gemini, with support for **English and Hindi** and optional crop/plant image analysis.
* 🌱 **Crop Recommendation & Analysis** – Uses soil and environmental parameters such as **N, P, K, pH, temperature, humidity, and rainfall** to recommend suitable crops and provide soil-management suggestions.
* 📊 **Machine Learning Integration** – Includes agricultural datasets and machine-learning functionality using **Python, Pandas, NumPy, and Scikit-learn**.
* 🌤️ **Weather Monitoring** – Provides location-based weather forecasts using **OpenWeatherMap**, with **Open-Meteo** as a fallback service.
* 🔐 **Secure Authentication** – Includes user registration and login using **Node.js, Express, MySQL, bcrypt, and JWT-based authentication**.
* 📱 **Responsive Web Interface** – Provides dedicated dashboards for prediction, weather, chatbot assistance, authentication, and agricultural information.
* 📈 **Data-Driven Recommendations** – Generates recommendations based on nutrient levels, soil type, rainfall, and environmental conditions.

### 🛠️ Technology Stack

**Frontend:** HTML5, CSS3, JavaScript
**Backend:** Node.js, Express, Python, Flask
**AI:** Google Gemini API
**Machine Learning:** Scikit-learn, Pandas, NumPy
**Database:** MySQL
**Authentication:** JWT, bcrypt
**APIs:** OpenWeatherMap, Open-Meteo, Kaggle

AgroSense aims to bridge agriculture and modern technology by providing farmers with an accessible platform for **AI-assisted decision making, crop management, environmental monitoring, and agricultural knowledge support**.
